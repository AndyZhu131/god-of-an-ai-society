# 12 人狼人杀 · 预女猎白首日

四名普通狼人、四名平民，外加预言家、女巫、猎人和白痴。随机发牌由 `--seed` 控制。玩家担任观察者，模型使用英文状态卡和英文场内发言。角色的选择由模型生成，法官用代码结算。

## 自己运行

启动 Ollama 并确认已有快速模式的默认模型 `phi4-mini:3.8b`。在项目根目录运行：

```powershell
python -X utf8 -m scenarios.werewolf --seed 17 --log werewolf_day1.json
```

用另一个种子可以换座位和身份分布。`--think` 默认使用 `gemma4:12b`，`--model` 可以覆盖任一模式的默认模型。想先检查命令和结算流程，可以加 `--backend scripted`，并换用 `--log werewolf_demo.json`。脚本演示的发言和动作由测试策略给出。

## 首夜和首日流程

1. **首夜**。狼人逐个私下商议，再同时提交刀票。女巫得知刀口并决定用药，预言家单独查验一人，猎人私下收到是否能开枪的状态。
2. **竞选**。全体同时决定是否上警，候选人依次发言并可退水。最初没上警的人可以投警长票。平票者再发言、重投一次，再平票或全部弃票则无警长。只剩一名候选人时直接当选。警长结算后，公布首夜死讯并处理技能、警徽和遗言。
3. **发言**。在场者按座次轮流发言。警长选顺时针或逆时针，最后发言。后发言者能听到前面的公开发言。
4. **投票**。存活且有投票权的玩家同步提交放逐票，警长票计 1.5。平票者发言后重投一次，平票者不参与重投；仍平票或无人得票则无人被放逐。放逐后处理技能、警徽和遗言。

法官采用暗牌、屠边。有技能触发时可以公开身份；普通出局只公布座位。好人出完四狼获胜，狼人屠尽平民或神职中的任意一边获胜。女巫不能自救，一夜至多用一瓶药。猎人被毒或作为最后一名神职出局时不能开枪。白痴首次被放逐时翻牌留场，保留发言权，失去投票资格，持有的警徽作废。

本情景用以下约定处理房规差异。狼刀允许自刀，同票用种子抽签，全弃刀则无刀。封闭的投票窗口按同时结算处理。狼人在自己的竞选或白天发言时可自爆，狼队在竞选票、放逐票前还有一次私下决定是否自爆的机会。首日警上自爆会延后警徽并结束白天，法官仍执行首夜死讯和遗言。下一夜和双爆的第二次触发超出本情景的范围。常规流程到首日放逐结算为止，未满足胜负条件时日志显示 `winner: null`。

## 日志怎么读

- `events` 是法官的全知时间线。包含警徽票型、场内发言、公开死讯和私下夜间行动。每条事件有独立编号及可见范围。
- `decision_trace` 保存每个座位作决定前实际收到的状态卡、合法选项、选择及简短自述。复盘可以检查真假预言家如何争警徽、狼队是否抱团或倒钩，以及投票在多大程度上跟随前面的发言。
- `summary` 包含真实身份和最终状态。运行途中只打印公开阶段和摘要，分析时再打开全知日志。

主要规则参考 [LAL 预女猎白赛事版型](https://werewolves.games/yu-nv-lie-bai/) 和 [《狼人杀官方》预女猎白赛事规则](https://langrensha.com/news/official/2018/09/25/26904_777006.html)。
