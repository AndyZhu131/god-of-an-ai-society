# 焚船之后

游戏设计 v0.1。12 名虚构居民，1790 至 1807 年共 18 个年度回合，1808 年迎船终章。玩家扮演观察和干预环境的神，居民作出自己的决定。

从船上搬下来的工具还在，船已经烧了。十几年间，岛上有人建立盟约，有人抢走工位，有人把技艺教给对手的孩子。直到外船出现，居民终于可以选择接触外界，也必须面对上一代曾经作过的选择。

## 时间线

| 时间 | 游戏节点 |
| --- | --- |
| 1789 | 邦蒂号兵变是开场背景。 |
| 1790 | 居民登陆后的第一年，是玩家能开始观察和干预的时点。每年依次观察、决策、结算。 |
| 1796、1799 | 两名开局仍年幼的岛民陆续年满 16 岁，从当年开始独立选择行动。 |
| 1797、1804 | 原型安排两次风暴。前一年的状态卡会显示风暴预警。 |
| 1798、1802 | 默认开局中，两名年长居民各完成自己的最后一个行动年。具体年份是用于验证交接的初始设定。 |
| 1808 | 美国船只 *Topaz* 的出现触发终章。居民第一次看到外船时才会收到接触选项。 |

1789 年兵变、1790 年抵岛及焚船、1808 年外船到访是历史锚点。原型的风暴、人物、夺取和结局属于虚构。居民包括不同出身的个人，阵营由实际行动与关系逐渐形成。 [英国国家海事博物馆](https://www.rmg.co.uk/collections/objects/rmgc-object-68763) · [皮特凯恩群岛政府历史资料](https://www.government.pn/history)

## 岛上只有三个核心地点

- **船具房**每年提供两个工位。它是练习船木工和修艇所需的唯一稀缺设施。通常开放申请，多人争用时按种子生成的轮换优先顺序分配。排到的行动才产生进度，同一年修同一处艇体只需一个工位，重复申请的结算记录为撞工。
- **聚居地**是居所、教学和存档的地方。公告板可以发布观点和承诺，已归档的图纸可以被后来者研习。能看到一份图纸的书目，与已经会用该技术，是两个不同状态。
- **海岸**有一艘虚构的待修小艇。艇体修好且航道已经复核时可以使用。复核航道需要领航技艺，在岸上完成，与修艇可以并行。两次风暴在轮末损坏已经修成的艇体，航道记录保留。居民必须有人能接手续修，才有机会把艇用到终章。

## 分年行动

每位能行动的居民每年选一件主要的事。另可留一条短消息、作出一项下年度承诺或发布一项夺取提案。消息和动作结果下一年可见。同一年的模型调用可以顺序执行，每人都依据同一时点冻结的状态卡决策。

| 行动 | 成本与结果 |
| --- | --- |
| 练习 | 花当年的主要行动。任一技艺经过两次成功练习即可掌握，船木工练习占工位，领航练习在海岸进行。 |
| 教人 | 已掌握技艺的人花一年向指定居民教学。学徒次年便可使用该技艺。学徒可以是尚未独立行动的孩子。 |
| 存档或研习 | 存档者花一年留下自己掌握的技艺。后来的人花一年研习这份档案获得技艺，并保留出处。 |
| 修艇或复核航道 | 船木工占一个工位修艇，领航者到海岸复核航道。结果均在轮末生效。 |
| 为人准备避风 | 预警后可花一年为自己或一名岛民准备避风物资。若当年轮初小艇可用，会领航的人可一次运送两人份。准备在风暴结算后用掉。 |
| 夺取或值守 | 支持一项船具房夺取提案，或守住当前使用规则。各花一年的主要行动。 |
| 休息 | 保留现状。这是居民可以主动选的行动。模型输出失败单独记录，不能用来推断居民拒绝了谁。 |

风暴前一年，居民可以用承诺公开认领下一年的保护对象，也可以当年就完成准备。下一年的状态卡显示已准备好的避风物资、各对象收到的承诺、无人承诺保护的人，以及未获保护就会死亡的人。认领允许重复，也可以失约。只有实际完成的避风准备能抵消风暴伤害。

居民从相同的基础行动能力、健康值 2 和零技艺开始。默认开局有 10 名成年人和两名分别为 10 岁、7 岁的孩子。年龄、在意的人和长期愿望各有差异。愿望可以是让家人平安、留下能被使用的技艺、保留离岛的机会。将要离场的居民能看到自己的剩余行动年数。每次风暴由引擎核对谁已做好避风准备，缺乏准备的人失去 1 点健康，健康归零时提前离场。年末先结算行动和风暴，再结算寿命。老师在最后一年完成的教学仍会生效。技术通过教学或存档流传，亲历的关系通过共同事件和留言留下。

轮初状态卡在居民身份旁标出当前健康值和上限，以及休息不会回血。模型先复述这些事实，再选动作。只剩 1 点健康值的居民仍可执行状态卡里的合法动作。引擎会核对复述，也会检查理由和公告中常见的虚报健康状态、等待回血、因受伤无法行动等说法。检查失败时提示真实状态并重试一次。连续失败按无效决策处理，日志单独保存被拒的输出。

## 夺取船具房

任何能行动的居民都可以提前一年在公告板提出夺取计划，为夺取成功后的两个工位各提名一位不同的居民。次年，居民可以支持其中一项计划或选择值守。至少两人支持，且支持人数严格超过值守人数和任何竞争计划，计划才胜出。平票沿用下一年的正常开放分配。成功计划只预留下一年的工位，获提名者离场或放弃使用时，空出的工位当年开放申请。公开记录实际出手的人及工位变更。夺取当年已经冻结的工位使用权照常结算。

两个人可以为了优先使用工具而合伙夺取。也可以一起替一个老木匠夺到最后一次修艇机会。被排除的人仍能在聚居地教学或存档，选谁学由他决定。居民也可以公开约定轮值，由愿意参加的人逐年兑现。角色卡列出与当前决定有关的几次兑现、失约、教学或夺取记录。承诺到期时，引擎记录是否兑现、是否因工位冲突等原因无法履行，或是否有合法机会却选择了其他行动。居民根据这些具体经历建立关系，也可以修复关系或改换搭档。

## 1808 年的接触

外船进入视野时，玩家能同时看到小艇是否可用、还有谁会领航，以及岛民各自愿不愿意接触外船。只要艇可用且有会领航的人愿意出发，就能触发一次接触。若多人愿意出发，按轮换优先顺序确定代表，其他居民可以在公开留言中表达自己的条件。接触成功后，首版中的外船为愿意离开的成年人提供搭乘机会。居民自行决定走或留。留岛者仍能使用小艇和档案，他们是否还能独立修艇与领航取决于留下的人掌握的技艺。

需要记下每个结局的来由。有人成功修艇却拒绝出发。有人无法接触外界，但保存了下一年仍能使用的技艺。还有人和已经成年的孩子一同离开，留下曾经帮过自己的对手继续照料工坊。玩家会看到这些选择及其证据。

## 玩家实际看到什么

- 画面顶部显示年份和即将发生的公开事件。船具房显示两个工位的下一年度使用人，小艇显示艇体和航道准备情况。
- 每年结束，只突出少数改变关系或结局的事件。点击「某人接手修艇」能倒查他从谁那里、在哪一年学会，也能看到那位老师是否已经离场。
- 玩家可以将一次已预警的风暴推迟一年，系统会向居民更新预报。推迟给居民更多准备时间，仍有可能让那次风暴发生在关键工匠离场以后。1808 年到访依然按历史年份触发。

### 终端玩家模式

- 开局选一项由日志与结局判定的目标。至少八人活到迎船，导师离场后仍有人使用他的技艺，或者有人登上外船且两门技艺同时保留在岛上。
- 将一张影响卡交给一名成年居民。预设卡有重视传承、愿意替人挡风和把承诺当回事。影响卡作为一条英文处事准则，只出现在该居民的状态卡上。
- 每局有两次干预机会。预警时可召开议事，让成年居民先独立表态，再一起看到计划并作出本年的正常决定。表态不耗年度行动，也不会直接产生避风保护。玩家还可将一场风暴推迟一年。
- 技艺被使用、避风准备实际生效、反复兑现承诺会产生可选遗产。局末能保存其中一张，附来源居民与事件号。下一局可将遗产特有的处事准则交给另一人。

### 性格数值试验

争夺倾向、担当倾向、守约倾向各用 0、1、2 代表低、中、高。状态卡同时列出数值和对应的英文行为准则，供该居民权衡。组织者的额外底线是拒绝支持给自己预留工位的提案，由引擎限制对应的投票动作。

独立基准冻结三个局面，分别比较居民是否支持夺取、是否替只剩 1 点生命值的岛民避险，以及是否放弃立即修艇去履行教学承诺。每对试验使用相同角色、合法动作与采样种子，仅改变一项性格及其对应准则。试验中的底线关闭，日志按实际主动作计数。

## 第一段要验证的故事

1795 年有人提出改变船具房的分配。1796 年两人共同夺取成功，1797 年船木工林被排除在工位外。风暴前，他把一年用在教刚能独立行动的少女，而没为自己准备避风。另一名居民可以自愿替他准备，也可以坚持把这一年留给自己。林在自己的寿命结束后离场。1804 年风暴再次损坏艇体，学生在 1805 年使用当年学到的技艺修艇。1808 年，她可以与另一名领航者一同促成接触。

首轮试跑可以先取这条故事的几个关键年，检查三个可观察结果。夺取有没有实际改变下一次分工，居民是否会因一次承诺兑现或落空而改换合作对象，以及技术是否在老师离场后被使用。完整首局再让这些事件从空白关系中自然形成。

运行时状态卡和动作描述使用英文，界面和复盘可以显示中文。首版采用本地快速模型，每年在轮初分发状态卡，每个动作在日志中关联事件编号。
